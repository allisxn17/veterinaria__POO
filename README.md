Se quiere construir una aplicación para una clínica veterinaria que permita gestionar la atención de las mascotas y apoyar al veterinario durante el proceso de diagnóstico.
Cuando una mascota llega a la clínica, el propietario proporciona sus datos y los de la mascota. Durante la consulta, el veterinario registra las diferentes molestias o síntomas que presenta el animal. A partir de estos síntomas, el sistema compara la información registrada con las enfermedades disponibles en el sistema y determina cuáles presentan una mayor coincidencia.

El sistema debe mostrar las posibles enfermedades de acuerdo con las molestias encontradas, indicando el nivel de coincidencia de cada una. Esta información sirve como apoyo para que el veterinario pueda analizar las posibilidades y establecer el diagnóstico correspondiente.
Una vez establecido el diagnóstico, el veterinario puede registrar el tratamiento que debe seguir la mascota, incluyendo los medicamentos, las indicaciones y la duración del tratamiento. Toda esta información debe quedar asociada al historial médico de la mascota para poder consultarla posteriormente.
Además, la clínica necesita gestionar sus citas, permitiendo programarlas y relacionarlas con una mascota y un veterinario. De esta manera, el sistema permite llevar un seguimiento de las atenciones realizadas y de la evolución médica de cada mascota.
